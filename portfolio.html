Personal project · In development

Family League Legacy

React · TypeScript · Node.js · Vercel Functions · ESPN API

The problem

A long-running family fantasy league needed a focused view of current standings and a foundation for preserving its history.

The contribution

Built a React/TypeScript dashboard and a Node.js API on Vercel that fetches ESPN data, validates it, and normalizes it into typed league models. Authentication cookies stay on the server.

The result

A deployed dashboard connected to a 12-team ESPN league, with sortable standings, wins-losses-ties records, scoring statistics, and accessible team details.

  • Table sorting preserves official rank and the current leader.
  • Loading, retry, and a clearly labeled sample fallback handle unavailable upstream data.
  • Automated tests cover API normalization, safe errors, and standings sorting.

Historical achievements are shown as unavailable until verified history is connected. Dedicated navigation and Supabase/PostgreSQL persistence remain planned.
